# 测试与验收

## 自动化

标准入口：

```powershell
task test
```

等价的底层命令：

```powershell
go vet ./...
go test ./... -count=1
```

CI 使用 `.github/workflows/test.yml`，在 `windows-latest` 上执行 vet、test 和 build。

重点测试：

- `pkg/vision`：LCS、gray-mask、colorful、模板匹配（合成图）。
- `pkg/screen`：加载上游 `commission_assistant.yml` 后区域坐标/类型正确。
- `pkg/assist/storyskip`：FakeRuntime + 脚本化帧覆盖 8 个状态场景。
- `internal/engine`：开始/暂停/恢复/停止、动作执行、异常退出释放输入。
- `internal/platform/windows`：坐标缩放/客户区换算纯函数；真实 Win32 测试无窗口时跳过。

## 后台输入与手柄

- 后台模式：游戏窗口失焦时仍能截图；`cursor_mode=never` 下点击不改变物理鼠标位置、不抢占前台。
- 精确点击：`cursor_mode=auto/always` 时用独立测试窗口验证目标命中；归位只在用户空闲时验证，避免测试脚本抢前台输入。
- 前台回退：设置 `input.mode=foreground` 后，点击前会激活游戏窗口。
- 手柄：确认 `ViGEmBus` 服务运行、`ViGEmClient.dll` 可加载；虚拟手柄能创建/移除，`xbox_a` 等按键可发送。
- 跨平台：`GOOS=linux GOARCH=amd64 CGO_ENABLED=0 go build ./...` 与 `GOOS=darwin ...` 通过；非 Windows 平台只提供 CLI 与核心能力。

## 真实《绝区零》验收

前置：游戏窗口化或无边框、16:9、关闭 HDR/缩放干扰；以管理员身份运行（如果游戏也是管理员）。

- [ ] 主线剧情出现“跳过”后 0.5 秒内点击，出现“确认”后点击。
- [ ] 纯对话按 0.5 秒间隔推进。
- [ ] 对话选项按“第一个/最后一个”配置选择。
- [ ] CG/过场有跳过按钮时正常跳过。
- [ ] 战斗、勘域、二级菜单、玩法引导中 60 秒内 0 点击。
- [ ] ALT-TAB 暂停、回游戏恢复。
- [ ] F10 急停，鼠标/键盘无残留按下。
- [ ] 移动/缩放窗口后坐标仍准确。
- [ ] 游戏退出后程序安全停止并提示。
- [ ] 删除 OCR 模型后启动会提示下载而不是崩溃。

## 轻量模式（托盘）手工验证

默认启动不建窗口，以下每一条都要在关闭其它窗口后单独验证：

- [ ] 启动程序后任务栏没有新窗口，只有托盘图标出现。
- [ ] 托盘右键菜单能弹出，内容顺序为：打开主界面 / 游戏列表（彩色圆点 + 状态）/ 剧情跳过（F11）、自动战斗（F12）开关 / 一行运行状态（彩色圆点 + 状态 + Home 下一步动作）/ CPU 与内存 / 退出。
- [ ] 托盘图标始终是程序图标，不随运行状态变色。
- [ ] 打开游戏后菜单里对应游戏左侧圆点变绿，未开的游戏是灰色；tooltip 变成「SkipAll · 游戏名 运行中 · N FPS · XMB」。
- [ ] 取消勾选剧情跳过（或自动战斗），重新打开菜单仍是未勾选；重新勾上恢复。
- [ ] 菜单里的 CPU/内存每 2 秒左右变化，数值与任务管理器同量级。
- [ ] 双击托盘图标打开主界面，窗口立刻出现（预热过，不应有 1 秒以上的空白）；窗口关闭后立即消失、托盘图标保留。
- [ ] 关窗后等 30 秒，任务管理器里该进程下不再有 WebView2 子进程（内存回落）。
- [ ] 销毁后再双击托盘，窗口能重新打开，且界面状态与关窗前一致（游戏名、FPS、日志都在）。
- [ ] 在游戏窗口前台按 Home：第一次启动（菜单圆点变绿 + 提示音），再按暂停（变琥珀），再按继续（变绿），再按一次回到已停止（变灰）。已停止时再按 Home 重新启动。
- [ ] 切到浏览器/其它应用后按 Home，不触发本程序，浏览器自己的 Home 行为正常。
- [ ] 按 F11 / F12 能开关剧情跳过 / 自动战斗，菜单里的勾选跟着变。
- [ ] 设置里改快捷键（例如 Home → F8）并保存，立刻生效，旧键不再触发。
- [ ] 窗口关闭期间引擎仍在后台跳过剧情（游戏里能看到点击生效）。
- [ ] 托盘 tooltip 随运行状态变化。
- [ ] 托盘菜单"退出"能真正结束进程，任务管理器里主进程与 WebView2 都消失。

## 性能观察

开发机记录 benchmark 趋势，不把单次数值当硬承诺：

- 1080p PrintWindow 截图目标 <50ms
- 单区域模板匹配目标 <20ms
- 小区域 OCR 目标 <150ms
- 整体循环目标 10 FPS

## 调试入口

```powershell
skip-all doctor --game zzz
skip-all doctor --game zzz --dump-frame
```

`--dump-frame` 会把当前截图、各区域框、OCR 结果保存到 `%APPDATA%\skip-all\debug\`，用于游戏更新后的画面修复。
