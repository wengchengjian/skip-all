# 战斗参数来源清单

自动战斗里每个可调数字都要能回答"它从哪来"。这张表按来源分三档：

- **上游**：直接等于上游实现里的常量/区域，改动必须同步上游
- **推导**：由上游坐标或尺寸换算得到（比如 4K 折半、模板尺寸 + 余量）
- **估算**：上游没有对应值，按画面特征估的，**只有实机才能定**

## 怎么用这张表

- "上游/推导"两档改了要重新核对上游；`games/*/areas_test.go` 会拦住坐标漂移。
- "估算"这档是**已知风险**：实机表现不对时优先调这里，而不是怀疑逻辑。
- 调参需要真实战斗画面。没有画面时只能保留估算值，并在改动说明里写清"未实机校准"。
